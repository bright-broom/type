# Generated content

Do not edit JSON files in this directory by hand.

- `consulting-playbook.json` and `consulting-prompts.json` are generated by `npm run import:consulting -- "/path/to/source.xlsx"`.
- `takken-glossary.json` is generated by `npm run import:takken -- "/path/to/source.tsv"`.

Commit importer changes and regenerated outputs together.
