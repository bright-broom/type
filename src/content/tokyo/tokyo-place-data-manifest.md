## 読みの生成と品質区分

1. 原典に読みがある場合は `official` として採用する。
2. 読みがない場合は SudachiPy 0.6.11 / sudachidict_core 20260723 で生成し、`sudachi-0.6.11-core-20260723` として「辞書補完（要確認）」を表示する。
3. 既知の誤読と入力不能文字は `tokyo-place-reading-overrides.json` で個別補正する。
4. `npm run import:tokyo` は件数、分類別件数、重複、文字種、原本ハッシュ、補正対象の存在を検証して生成する。

辞書補完は公式読みとして扱わない。読みの一次資料が得られた語は、補正ファイルへ根拠区分とともに追加する。
